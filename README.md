# 虫虫们的幸福生活

绿虫虫和粉虫虫的小相册。吃饭要一起，出去玩也要一起，没事就黏着。

## 打开网站

https://ephemeral233.github.io/chongchong-happy-life/

电脑横屏、手机竖屏都可以浏览。包含海参崴、呼和浩特、天津、阿那亚四本旅行相册，以及三文鱼和日常回忆。

## 内容怎么保存

- 所有人打开网站，都能看到同一份已发布相册。
- 点击加照片或记一笔，会先提示进入本机草稿。草稿只保存在当前浏览器。
- 页面不会连接原来的 chatgpt.site，也不需要 ChatGPT 登录。
- GitHub Pages 不能运行相册后台，这个版本没有口令式共同编辑功能。编辑口令不会出现在源码中。
- 已发布内容保存在 journal.json，图片位于 assets/。每次打开都先展示已发布内容；本机草稿需主动打开。

## 发布新回忆

1. 在网站中打开本机草稿，添加内容，再下载备份。
2. 在本项目目录运行：

```sh
node tools/publish-album.mjs /完整路径/虫虫们的幸福生活-备份.json
```

3. 提交 journal.json 与新增图片并推送到 main，GitHub Pages 会更新。

发布会公开这些照片、文字和愿望。只在自己的电脑中操作，无需提供网站编辑口令。

## 本地预览

用任意静态 HTTP 服务打开项目目录，例如 Python 的 `python -m http.server 8080`，然后访问 localhost:8080。
